## 默认配图

`src/resources.ts` 的 `defaultDishPhoto` 仅从抽象清单选图，不再根据肉、鱼、虾等大类选择真实菜品照片。同一菜名的哈希在列表、菜单、详情及刷新后保持一致；无名记录使用 id。所有本地图片加载失败后的最终兜底也是中性的抽象图形。

已有有效 HTTP(S) 参考图仍优先显示；无图、远端加载失败或远端尺寸不足时使用抽象封面。详情注明“餐桌意象 · 非菜品实拍”。

## 装饰轮播

`DecorativePhoto` 将原 32 张图片用于登录页、欢迎页、首页横幅和侧栏装饰。各区域独立打乱顺序，用完一轮再重排，轮与轮之间避免相邻重复。欢迎页菜名与当前照片同步。

每张停留约 12–18 秒，下一张解码完成后以 1.2 秒非线性淡入覆盖当前图片，容器尺寸保持固定。图片失败时跳过；只有下一张进入轮播时才额外加载，避免一次下载完整图库。

支持暂停/播放；鼠标悬停、焦点进入、区域离开视口或页面进入后台时暂停。侧栏图片嵌于现有按钮内，使用父按钮焦点暂停，避免嵌套按钮。`prefers-reduced-motion: reduce` 下不启动轮播，静态展示可用图片。
